# 한국어 커머스 쇼츠 제작 파이프라인

가지고 있는 제품 영상을 **15~30초 세로 쇼츠**로 재편집합니다.
장면 단위 인덱싱 → 대본 → 나레이션 → 자막 → 렌더 → 19항목 자동 검수까지 한 줄로 이어집니다.

유료 AI 영상 생성은 쓰지 않습니다. **ffmpeg + Remotion 로컬 렌더 + ElevenLabs TTS** 만 씁니다.

---

## 이게 다른 쇼츠 도구와 뭐가 다른가

AI로 영상을 **생성**하거나 롱폼에서 **추출**하는 도구는 이미 많습니다.
이건 **이미 가진 실제 제품 영상을 재편집**하는 쪽이고, 한국 커머스에 맞춰져 있습니다.

**규칙이 실측입니다.** 같은 제품을 다룬 한국 쇼츠 6편(조회수 1.6만~793만)을
프레임 단위로 대조해서 얻은 수치로 만들었습니다.

| | 실측값 |
|---|---|
| 컷 중앙값 | 1.2~1.8초 |
| 문장 사이 쉼 | 평균 0.30초 · 최대 0.60초 |
| 나레이션 음높이 폭 | 9.7~14.3 반음 |

**한국어 나레이션 규칙이 도구에 들어 있습니다.**
1인칭 후기 톤 강제, 합쇼체(`~합니다`) 차단, 중간 문장을 `~거든요`로 닫으면 경고,
같은 어미 3연속 경고, 마지막 문장 억양 하강 경고.

**쿠팡 파트너스 대응.** 영상 상시 광고 표시, 플랫폼별 CTA(댓글 기반),
유튜브·인스타·틱톡 각각의 링크 방식과 고지 문구를 카피킷이 만들어 줍니다.

---

## 19항목 자동 검수

렌더가 끝나면 `check_render.py` 가 완성본을 기계로 검사합니다.
아래는 **실제로 오래 안 잡혔던 것들**이라 하나씩 검사로 만들었습니다.

- 컷 경계에 낀 **1프레임 검은 화면** (초당 30프레임에서 눈으로 못 잡습니다)
- 원본에 박힌 자막이 장면 경계를 넘어 **딸려 들어오는 것**
- 문장 사이 "쉼"에 **말소리가 남아 있는 것** (타임스탬프가 깨지면 생깁니다)
- 플랫폼 블록 하나에서 **파트너스 고지가 빠진 것**
- 컷 중앙값 이탈 · 소재 편중 · 같은 소재 연속 · 자막↔음성 불일치 · 썸네일 누락 등

검사에 걸리면 **데이터를 억지로 맞추지 마세요.** 소재나 대본이 부족하다는 신호입니다.

## 시작하기

**처음이라면 → [`처음부터_따라하기.md`](처음부터_따라하기.md)**
프로그램 설치부터 첫 영상까지 순서대로 안내합니다.
(ElevenLabs 키 발급 · watch 스킬 설치 · 샤오홍슈 소재 다운로드 포함)

이미 환경이 있다면 [`설치_먼저_읽기.md`](설치_먼저_읽기.md) 요약으로 충분합니다:

```bash
npm install
cp .env.example .env          # ElevenLabs 키 넣기
python new_project.py --name "제품명"
# raw/ 에 소재 영상을 넣고
python prep_sources.py --dir raw --out sources
python index_sources.py --dir sources --cuts 18
# out/storyboard.png 를 보고 라벨을 채운 뒤 remix.json 작성
python make_remix.py
npx remotion render src/index.jsx Remix output/완성본.mp4 --crf 18
python thumb.py
python check_render.py --shots 18
```

Claude Code 로 쓰신다면 `SKILL.md` 를 `~/.claude/skills/shopping-shorts/` 에 넣으면
8단계를 알아서 따라갑니다. `프롬프트_템플릿.md` 에 요청 양식이 있습니다.
